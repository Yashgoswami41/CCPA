About This Repository

This repository contains practical exercises, lab configurations, screenshots, and related files created during my Check Point Certified PenTesting Associate (CCPA) training.

Purpose

The purpose of this repository is documentation only. It is intended to maintain a record of the practical exercises performed during training, the configurations used, and the learning progress.

Topics Covered

Network configuration and routing

Static routing

RIP, OSPF, and EIGRP

DHCP configuration

Serial interface configuration

GNS3 and Packet Tracer lab exercises

Network connectivity testing using ping

Other related networking practicals completed during training

Disclaimer

All files and materials in this repository are maintained strictly for educational and documentation purposes as part of training.

Note

This repository serves as a personal training record. The contents may be updated as additional practical exercises and configurations are completed.
